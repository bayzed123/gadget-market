# Fonts used on the rendered packaging

These fonts are only used by `scripts/render-gadget/` to print brand names and labels on the starter product
renders. They are not loaded by the shop itself (the shop uses Google Fonts links).

| File | Font | Licence |
|---|---|---|
| `cormorant.woff2`, `cormorant-italic.woff2` | Cormorant Garamond — the Cormorant Project Authors | SIL Open Font License 1.1 — [OFL-Cormorant.txt](OFL-Cormorant.txt) |
| `jost.woff2` | Jost — the Jost Project Authors (indestructible type*) | SIL Open Font License 1.1 — [OFL-Jost.txt](OFL-Jost.txt) |
